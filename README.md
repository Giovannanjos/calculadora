
# Calculadora em Python 🐍

Uma calculadora simples de terminal desenvolvida em Python como projeto de estudo.

## Funcionalidades

- Adição, subtração, multiplicação e divisão
- Validação dos dados digitados
- Tratamento de divisão por zero
- Histórico dos cálculos realizados
- Testes automatizados com `unittest`

## Como executar

Certifique-se de ter o Python 3 instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
python main.py
```

## Como executar os testes

Para executar os testes automatizados, utilize:

```bash
python -m unittest discover -v
```

## Tecnologias utilizadas

- Python 3
- unittest para testes automatizados
- Git e GitHub para controle de versão e compartilhamento do projeto

## Objetivo

Este projeto foi desenvolvido para praticar lógica de programação, funções, organização de código em módulos, tratamento de erros e testes automatizados.
